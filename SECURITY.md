# Безопасность / Security

Поддерживается текущая версия сайта из `main`. Сайт статический: без авторизации, базы данных, форм отправки и выполнения отображаемых терминальных команд.

## Сообщение об уязвимости

Свяжитесь с владельцем в [Telegram](https://t.me/slipcast666). Не публикуйте секреты и чувствительные данные в Issues. Срок ответа заранее не гарантируется. Если GitHub предлагает приватный отчёт Security → Report a vulnerability, его также можно использовать.

## Меры защиты

- Клиентский JavaScript использует `textContent` для данных репозиториев; HTML из GitHub не исполняется.
- GitHub API вызывается только при сборке. Перед публикацией проверяется публичность, владелец и категория репозитория. В артефакт попадают только необходимые публичные поля.
- Токен GitHub существует только в задаче синхронизации и не публикуется. Checkout не сохраняет учётные данные в Git config. Права по умолчанию — `contents: read`; `pages: write` и OIDC доступны отдельной задаче deploy.
- Pull request не выполняет deploy и не получает шаг синхронизации с токеном.
- Actions закреплены полными SHA. Зависимостей npm нет.
- Сборка добавляет meta CSP: локальные скрипты и хеши конкретных встроенных скриптов; сетевые запросы только к своему сайту, объекты и отправка форм запрещены. Встроенные стили разрешены. Это не утверждение о наличии HTTP-заголовков CSP на стороне GitHub Pages.
- Превью сайтов — iframe с `sandbox="allow-scripts"`, без `allow-same-origin`, без фокуса и без обработки нажатий внутри превью.
- В браузере сохраняются только язык интерфейса и признак просмотренного вступления. Учётные данные и приватные проекты не хранятся.

## Ограничения

GitHub Pages не даёт произвольно настроить все защитные HTTP-заголовки. Изменения публичности репозиториев отражаются после очередной успешной синхронизации; ранее публичные сведения могут оставаться в кэше CDN и истории Git. Превью зависят от внешних сайтов и их политик встраивания. Открытие Telegram зависит от установленного приложения и настроек браузера.

This static site does not execute displayed shell commands. Report security concerns privately to the owner. Only public repository metadata is published; credentials remain in GitHub Actions.
