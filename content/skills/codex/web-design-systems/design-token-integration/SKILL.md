# Интеграция дизайн-токенов

В Codex сверьте AGENTS.md и существующие токены. Проверьте макет в доступном превью на тех же размерах, которые записали в отчёте.

1. Инвентаризируйте цвет, размеры и интервалы изменяемого компонента. Разделите базовые значения и семантические роли вроде текста ошибки.
2. Сопоставьте роли с текущей системой токенов. Если нужна новая роль, покажите её применение минимум в одном реальном состоянии.
3. Сравните обычное состояние, фокус, наведение и отключение. Сдайте карту значений и перечень проверенных тем.
