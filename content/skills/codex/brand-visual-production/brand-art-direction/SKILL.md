# Арт-дирекция визуальной кампании

В Codex сверьте правила проекта в AGENTS.md и проверяйте предоставленные изображения в доступном просмотрщике.

1. Сведите аудиторию, задачу и каналы в короткий бриф. Для каждого референса выделите только применимую общую особенность.
2. Предложите два самостоятельных направления с композицией, цветом, характером изображений и примером применения в малом формате.
3. Для выбранного направления сдайте правила адаптации, список контрольных размеров и критерии приёмки.
