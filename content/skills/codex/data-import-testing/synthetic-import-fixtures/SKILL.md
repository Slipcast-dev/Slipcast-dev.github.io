# Синтетические данные для импорта

В Codex найди правила тестов в AGENTS.md и создай файлы в принятом каталоге фикстур. Используй штатный тестовый раннер.

1. Возьми согласованную схему полей: типы, обязательность, ключи, кодировки и правила дат. Для каждого файла укажи конкретную проверяемую гипотезу.
2. Создай вымышленные строки для нормального импорта, пустого поля и null, дубля, значения на границе и числа в неверном формате. Для CSV добавь кавычки, разделитель внутри значения, Unicode и нужный вариант перевода строк.
3. Оставь небольшие файлы с читаемыми значениями. Для больших объёмов используй фиксированное начальное значение генератора. Рядом дай ожидаемые счётчики принятых и отклонённых записей.
4. Запусти штатный импорт в тестовое хранилище и сравни с ожиданиями. При отсутствии среды выполни проверку формата и зафиксируй оставшиеся проверки.
