# Редактирование и пакетный экспорт изображений

Прочитайте AGENTS.md, найдите исходники, прежние рецепты обработки и правила хранения производных файлов. Выберите доступный редактор для масок и ретуши или существующий локальный сценарий для одинаковых преобразований.

1. Зафиксируйте исходники и допустимые правки. Для каждой выходной версии запишите размер, правила кадрирования, формат, профиль, режим прозрачности и допустимый вес. Сохраните мастер со слоями или историю преобразований.
2. Испытайте обработку на изображениях с разной ориентацией, профилями и прозрачностью. Исправьте ориентацию до кадрирования, примените цветовое преобразование в профиль назначения, согласуйте фон для форматов без альфа-канала. Не увеличивайте маленькие изображения молча, если макет требует исходной детализации.
3. В отдельном каталоге запустите экспорт с предсказуемыми именами. Проверьте коллизии имён до записи и сверяйте каждый получившийся файл с назначением по размеру, профилю и прозрачности. Сопоставьте пробные выходные файлы с предпросмотром мастера.
4. Передайте мастер, экспортный рецепт и реестр «исходник, версия, преобразования, файл, статус». Зафиксируйте исключения и фактические параметры, чтобы прогон можно было повторить.
