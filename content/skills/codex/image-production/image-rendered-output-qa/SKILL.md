# Визуальная проверка экспорта изображений

Прочитайте AGENTS.md и найдите утверждённый мастер, рецепт экспорта и фактические файлы поставки. Используйте доступный просмотр изображений для сравнения, локальную утилиту метаданных для проверки профиля, битности, альфа-канала и размера.

1. Сопоставьте файлы по реестру. При сравнении сведите мастер и экспорт к одной ориентации, области кадрирования и цветовому пространству. Для прозрачного изображения проверьте композицию на светлом и тёмном фоне.
2. На 100 % просмотрите зоны ретуши, границы масок, градиенты и мелкие детали. Ищите ореолы, ступени яркости, выбитые света, блочные следы сжатия и случайные потери прозрачности. Дополнительно проверьте вид при целевом масштабе.
3. Для ожидаемо идентичных областей используйте наложение или карту различий после нормализации размеров и цветового пространства. У сжатых экспортов оценивайте реальные визуальные проявления, поскольку небольшое различие пикселей может быть ожидаемым.
4. Для каждого дефекта укажите файл, координаты или область, масштаб, фон, ожидаемый вид и результат. После правки проверьте затронутый файл повторно и подтвердите обновление именно сданной версии.
