# Сортировка файлов по правилам

В Codex начни с AGENTS.md и проверь, где проект хранит оригиналы, тестовые копии и журналы. Выполняй пробный прогон в отдельной рабочей папке.

1. Определи приоритет правил и признаки, например расширение, дату документа и исходную папку. Для неопределённого результата назначь очередь проверки.
2. Сформируй план путей без переноса. Сверь количество совпадений с каждым правилом и отдельно выдели дубли и вложенные каталоги.
3. В тестовой папке проверь повторный запуск, относительные пути и случай с уже существующим файлом. Сохрани исходный путь для каждого перенесённого файла.
