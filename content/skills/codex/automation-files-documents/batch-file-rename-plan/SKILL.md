# Пакетное переименование файлов

В Codex начни с AGENTS.md и проверь, где проект хранит оригиналы, тестовые копии и журналы. Выполняй пробный прогон в отдельной рабочей папке.

1. Запиши правила имени, регистр, расширение и способ нумерации. Построй таблицу «старое имя, новое имя» на полном наборе входов.
2. В пробном прогоне найди совпадения, зарезервированные имена, слишком длинные пути и коллизии после нормализации Unicode. Укажи проблемные строки.
3. Проверь переименование на копии. Сохрани карту обратных имён, число изменённых файлов и исключения. Сравни содержимое по контрольной выборке.
