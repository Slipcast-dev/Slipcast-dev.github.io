# Сопоставление полей между сервисами

В Codex сверяй AGENTS.md и контракт собственного сервиса. Для проверок используй сохранённые образцы и штатный локальный адаптер.

1. Зафиксируй версии и состав исходного события и целевой записи. Укажи обязательность, типы, единицы и преобразования с примером.
2. Локально проверь полное событие, отсутствующее обязательное поле, новую необязательную часть и неподдерживаемую версию.
3. Сдай карту преобразования и перечень событий, требующих ручной обработки. Для отклонений укажи причину без копирования чувствительных значений в журнал.
