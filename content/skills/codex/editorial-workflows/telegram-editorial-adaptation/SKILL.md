# Адаптация статьи для Telegram

В Codex открой указанный документ и доступный гайд голоса. При работе в репозитории проверь редакционные правила в AGENTS.md.

1. Определи аудиторию, цель и тон. Отметь факты, имена, даты и ссылки, которые надо сохранить.
2. Сделай короткий пост с одной основной мыслью, серию из самостоятельных частей и дайджест с краткими тезисами. Оставь ссылки рядом с утверждениями, которые они подтверждают.
3. Сверь каждый вариант с материалом: сохрани диапазоны, оговорки и точность цитат. Сомнительные места пометь для проверки редактором.
4. Верни готовые черновики и короткий список вопросов редактору, если части исходника расходятся.
