# Переносимость скилла между Codex и Claude Code · Codex

Соблюдай инструкции AGENTS.md и проверяй изменения штатными инструментами репозитория.

1. Выбери один сценарий, общий минимальный вход и эталон результата. Зафиксируй версии клиентов, модели и доступные инструменты. Проверь имя скилла, YAML, пути к ресурсам и ограничения проекта.
2. В Codex вызови скилл явно через $имя и сверяйся с AGENTS.md. Для Claude Code подготовь тот же вход и запуск через /имя. Выполняй только в разрешённых тестовых проектах. При отсутствии второго клиента запроси его лог или отметь проверку отложенной.
3. Сравни отдельно обнаружение скилла, фактическую загрузку, набор инструментов, формат результата и внешние эффекты. Для каждого расхождения укажи среду, доказательство, минимальную правку и повторный тест.
