# Проверка структурированного ответа модели

1. Найди согласованную схему и минимальный валидный пример. Уточни типы, обязательность, допустимость пустых значений и правила для неизвестных полей.
2. Раздели проверки парсинга, валидации схемы и предметного смысла. После проверки типов проверь связь полей, допустимые диапазоны и согласованность значений с исходным примером.
3. На локальных фикстурах проверь валидный ответ, отсутствие обязательного поля, пустой результат и лишнее поле. Добавь один случай, в котором ответ проходит схему, но противоречит входу. По возможности включи пример для каждой поддерживаемой версии схемы.
4. Для сбоя запиши имя фикстуры, путь поля, ожидаемое и полученное значение. Если данные нельзя однозначно получить из входа, используй явно согласованный способ обозначить неопределённость.

Результат — отчёт о соответствии формату и содержанию с воспроизводимыми примерами.
