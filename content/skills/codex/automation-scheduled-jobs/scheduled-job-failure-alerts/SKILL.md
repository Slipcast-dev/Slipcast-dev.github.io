# Уведомления о сбоях заданий

В Codex проверь AGENTS.md, штатный способ запуска и путь к журналам. Используй явные тестовые аргументы для одного запуска.

1. Составь таблицу «успех, временный сбой, окончательный сбой, восстановление». Для каждого состояния опиши условия уведомления.
2. Проверь на локальной заглушке повтор одной ошибки, два разных задания и недоступный канал. Сверь группировку и задержку между уведомлениями.
3. В уведомлении оставь имя задания, время, безопасную ссылку на журнал и следующий шаг. Проверь, что чувствительные поля не попадают в сообщение.
