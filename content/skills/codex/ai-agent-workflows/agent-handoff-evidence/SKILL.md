# Передача работы между агентами

1. Опиши цель, границы и критерий завершения одним коротким абзацем. Укажи файлы, в которых следующий исполнитель имеет право работать, и материалы, которые ему нужны для проверки.
2. Привяжи каждое существенное утверждение к наблюдаемому доказательству. Используй путь, номер строки, вывод проверенной команды или идентификатор артефакта. Сохрани только необходимые фрагменты с учётом приватности данных.
3. Зафиксируй состояние каждой проверки как «прошла», «не прошла» или «не запускалась». Перечисли недостающие условия и ограничения доступа. Отдельно укажи решение, которое нельзя принять без владельца проекта.
4. Закончи одним следующим действием, проверяемым результатом и ожидаемым ответом исполнителя. Если работа параллельная, раздели области записи или укажи порядок применения изменений.

Результат — самодостаточная записка с полями «цель», «сделано», «доказательства», «открытые вопросы» и «следующее действие».

## В Codex

Сопоставь область передачи с применимыми AGENTS.md. Если в Codex есть разрешённая возможность делегирования, передавай только минимальный контекст и проверяемые результаты. В остальных случаях сохрани записку для пользователя или следующей сессии.
