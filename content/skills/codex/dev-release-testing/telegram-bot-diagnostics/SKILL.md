# Диагностика Telegram-бота

В Codex найди обработчики и тесты по AGENTS.md и структуре репозитория. Используй существующие фикстуры и запуск целевого теста.

1. Определи наблюдаемый сбой и один ожидаемый сценарий. Работай с очищенными журналами и локальными событиями без токенов, телефонов и идентификаторов реальных чатов.
2. Сопоставь событие с маршрутом обработчика и состоянием диалога. Локально проверь команды, повторное событие с тем же ID, неизвестный тип события и сбой зависимости.
3. При повторе сравни наблюдаемые побочные эффекты с контрактом обработчика. Если исследуешь отправку сообщений, используй заглушку и посчитай обращения к ней.
4. Дай краткий диагноз с фрагментом очищенного журнала, минимальным тестом регрессии и фактическим результатом выполнения.
