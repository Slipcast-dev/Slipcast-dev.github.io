# Состояния каталога магазина

В Codex используйте AGENTS.md и существующие каталожные фикстуры. Проводите проверку только в локальном превью.

1. Создайте товары с несколькими вариантами, без остатков и без изображения. Для каждого опишите видимость, доступность кнопки и итоговое сообщение.
2. Проверьте сочетания фильтров и сортировку, возврат из карточки, пустой результат и восстановление позиции списка.
3. Сдайте матрицу состояний и выделите ситуации, где покупателю невозможно понять, почему вариант недоступен.
