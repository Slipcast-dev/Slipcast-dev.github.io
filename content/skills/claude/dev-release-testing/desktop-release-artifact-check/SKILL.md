# Приёмка релизных файлов macOS и Windows

В Claude Code сверь CLAUDE.md и получи список файлов через Glob. Отдельно покажи данные, прочитанные из манифеста, и результаты команд, если Bash доступен.

1. Зафиксируй ожидаемую версию, список файлов, архитектуры, минимальные версии ОС и опубликованные контрольные суммы. Источник каждого требования укажи отдельно.
2. На тестовой копии проверь, что каждый файл доступен по ожидаемой ссылке, имеет нужное имя, ненулевой размер и совпадающий SHA‑256, если предоставлен эталон. Сохрани фактические значения.
3. На macOS проверь сведения о подписи и нотариальном заверении доступными штатными средствами. На Windows проверь подпись Authenticode и сведения об издателе и версии. Для неподдерживаемой в текущей среде ОС перечисли свидетельства, которые ещё нужно получить.
4. Сопоставь платформу и архитектуру из метаданных с карточкой скачивания и описанием релиза. Выдай таблицу «файл · версия · архитектура · хеш · подпись · статус» и перечисли условия, блокирующие выпуск.
