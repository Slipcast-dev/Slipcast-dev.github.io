# Проверка резервной копии

В Claude Code сначала прочитай CLAUDE.md и документацию восстановления. Используй локальный Bash только с путями к тестовым копиям.

1. Согласуй входной архив, ожидаемый состав и новую пустую папку для восстановления. Сохрани источник и рабочие данные в режиме чтения.
2. Проверь свободное место и пути в архиве. Для программного восстановления используй штатную процедуру приложения на тестовой копии с отдельной конфигурацией.
3. Сверь число файлов, объём, хеши из манифеста и выборку записей, включая имена с Unicode и пустые каталоги, если они важны для проекта. Укажи, какие свойства удалось проверить.
4. Отчитайся о времени, восстановленных данных, расхождениях и возможности повторить проверку. Приведи путь тестового результата и явно отметь непроверенные области.
