# Согласованность транзакций

В Claude Code прочитайте CLAUDE.md, схему и тестовые сценарии нужного сервиса. Используйте только тестовое подключение и доступные команды Bash.

1. Опишите инварианты до и после операции и перечислите записи, которые меняются вместе.
2. На локальной базе проверьте успех, ожидаемый сбой между шагами и повтор того же запроса. Сравните итоговые записи и подтверждённые побочные эффекты.
3. Отдельно опишите состояние после сбоя и способ повторить проверку. При изменениях добавьте тест на нарушенный инвариант.
