# Совместимая пагинация API

В Claude Code прочитайте CLAUDE.md, схему и тестовые сценарии нужного сервиса. Используйте только тестовое подключение и доступные команды Bash.

1. Запишите контракт клиента: тип курсора, фильтр, порядок сортировки и формат пустой страницы. Проверьте стабильный дополнительный ключ при равных значениях.
2. На фиксированном наборе данных пройдите границы страниц, пустой результат и неизвестный курсор. Если при параллельных изменениях допускаются пропуски, зафиксируйте эту семантику.
3. Сравните ответы текущего и предыдущего потребителя. Сдайте примеры запросов, ожидаемые ответы и тесты на границы.
