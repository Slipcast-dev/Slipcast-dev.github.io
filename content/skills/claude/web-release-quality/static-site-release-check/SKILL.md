# Приёмка статической сборки

1. Уточни схему размещения из конфигурации сборки: корень сайта либо путь проекта. Выполни штатную production-сборку и открой её готовый каталог тем же способом, которым статический сервер будет раздавать файлы.
2. Проверь главную, вложенную страницу, переключение языка и один сценарий скачивания. Для каждого маршрута зафиксируй URL, ожидаемый файл и фактический ответ. Проверяй конечные адреса и относительные ресурсы с учётом пути размещения.
3. Сверь список публичных файлов с правилами проекта. Убедись, что служебные исходники и локальные файлы не оказались в выдаче. Для архивов сверь доступность по ссылке и содержимое с выпускным манифестом, если он существует.
4. Проверь варианты со слешем, виртуальную страницу 404 при её наличии и смену версии ссылки на ресурс после пересборки. Для языковых страниц сверяй ссылки переключения и адреса метаданных с доступными маршрутами.

Результат — отчёт с командой сборки, проверенными путями и наблюдаемыми расхождениями. Сохраняй действия в локальном окружении.

## В Claude Code

Прочитай CLAUDE.md и конфигурацию проекта через Read и Grep. Запускай штатную сборку и локальный сервер через Bash, а браузерную проверку выполняй только доступным в сессии инструментом.
