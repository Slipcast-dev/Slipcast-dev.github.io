# Проверка бюджета веб-производительности

1. Найди принятые пороги и эталонную сборку. При отсутствии порогов сначала зафиксируй сравнительные метрики для согласования. Выбери ключевые маршруты и условия измерения.
2. Измерь объём сборки, объём ресурсов, загружаемых выбранным маршрутом, и число запросов. Различай размер на диске и размер передачи. Отметь, включает ли измерение индексы, шрифты и ресурсы, загружаемые после действия.
3. Если доступен браузерный раннер, выполни несколько одинаковых прогонов локально. Запиши размер окна, состояние кеша и параметры ограничения сети. Для нестабильных результатов покажи медиану и диапазон.
4. Привяжи превышение к файлу или запросу и предложи шаг с проверяемым эффектом. При исправлении повтори тот же сценарий и сравни с исходной сборкой.

Результат — таблица «маршрут, метрика, порог, результат» и перечень измерений, которые остались недоступны.

## В Claude Code

Сверь CLAUDE.md и принятые параметры производительности. Для замеров используй локальные команды через Bash и уже подключённый браузерный раннер, если он доступен.
