# Контроль изменений формата RSS, CSV и JSON · Claude Code

Соблюдай правила проекта в CLAUDE.md и используй разрешённые инструменты текущей сессии.

1. Сверь сохранённые RSS, CSV или JSON с контрактом парсера. Используй публичные или разрешённые образцы и соблюдай ограничения источника. Зафиксируй ключ записи и обязательные поля.
2. Сравни схему и разобранный результат для каждой пары: добавленные поля, изменившиеся типы, пустые значения, потерянные и повторные записи. Для спорных случаев укажи исходную строку или узел.
3. Подготовь отчёт с изменением, влиянием и критерием повторной проверки. После правки повтори прогон на старых и новых образцах, если доступны парсер и разрешённый стенд.
