# Приёмка установщиков macOS и Windows · Claude Code

Соблюдай правила проекта в CLAUDE.md и используй разрешённые инструменты текущей сессии.

1. Составь матрицу для поставленных пакетов: ОС, архитектура, канал, предыдущая версия и ожидаемый результат. Сверь источники подписей и хешей из доступных артефактов.
2. Исполни доступные проверки на выделенных тестовых машинах с синтетическими данными. Проверь чистую установку, запуск, обновление, штатный откат и удаление. Для недоступной платформы подготовь сценарий и критерии, оставив статус «ожидает прогона».
3. Верни решение о готовности по каждому пакету с логом или снимком. Считай потерю данных, неподтверждённую подпись и несовместимость с заявленной платформой блокерами выпуска.
