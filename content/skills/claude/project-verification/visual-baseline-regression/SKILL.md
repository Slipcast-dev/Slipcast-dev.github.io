# Визуальная регрессия по эталонным снимкам · Claude Code

Соблюдай правила проекта в CLAUDE.md и используй разрешённые инструменты текущей сессии.

1. Сопоставь приложенные снимки по странице, состоянию, размеру и теме. Запроси недостающие пары. При возможности проверь одинаковые тестовые данные, масштаб и загруженные шрифты.
2. Разбирай отличия от общего к частному: геометрия, текст, элементы управления, видимость фокуса. Для наблюдения укажи область снимка и влияние на читаемость или действие.
3. Подготовь отчёт с запланированными изменениями, регрессиями и случаями, которые нельзя подтвердить по снимку. Не объявляй эквивалентность без пары изображений или фактической проверки.
