# Рабочий сценарий PowerShell

В Claude Code сверь CLAUDE.md и доступную оболочку. Просмотри исходные файлы через Read, а команды запускай только на поддерживаемой локальной платформе.

1. Передавай входной и выходной пути явными параметрами. Обработай пробелы, Unicode, отсутствие файла и конфликт целевого пути.
2. Проверь пробный прогон без изменений, затем штатный запуск на временной папке. Отдельно проверь отказ доступа и повторный запуск.
3. Сохрани команду, ожидаемый код завершения и пример журнала. Укажи, какие действия выполняются интерактивно и какие подходят для запуска по расписанию.
