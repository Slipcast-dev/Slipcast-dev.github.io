# Локальная автоматизация AppleScript

В Claude Code сверь CLAUDE.md и доступную оболочку. Просмотри исходные файлы через Read, а команды запускай только на поддерживаемой локальной платформе.

1. Уточни, какие команды приложение реально предоставляет, и проверь имена объектов на небольшой тестовой копии.
2. Обработай незапущенное приложение, отсутствующий объект и отклонённый доступ. Для повторного запуска проверь, какие объекты уже созданы.
3. Сохрани команду запуска, требования к разрешениям и ожидаемый эффект. Проверь на вымышленных данных с безопасным завершением при ошибке.
