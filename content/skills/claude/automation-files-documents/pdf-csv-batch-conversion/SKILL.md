# Пакетное преобразование PDF и CSV

В Claude Code сверь CLAUDE.md, собери список входов через Glob, изучи правила на нескольких образцах через Read и выполняй операции над копиями через доступный Bash.

1. Согласуй целевой формат и образцы. Отличай PDF с текстовым слоем от сканов, а для CSV зафиксируй кодировку, разделитель и локаль чисел.
2. Преобразуй контрольную выборку с многострочными ячейками, Unicode и пустыми значениями. Сравни число страниц, строк и значимые поля с источником.
3. Сохрани результаты отдельно и подготовь отчёт по пропускам и ошибкам преобразования. Для результата OCR укажи поля, требующие ручной сверки.
