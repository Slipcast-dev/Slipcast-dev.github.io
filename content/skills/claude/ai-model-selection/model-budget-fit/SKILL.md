# Выбор модели под бюджет

В Claude Code сверьте CLAUDE.md и допустимые модели через локальные настройки. Оцените существующие записи через Read и запускайте тесты через Bash по явной задаче.

1. Согласуйте допустимые ошибки, бюджет и задержку до начала сравнения. Возьмите контрольные задачи из нескольких классов сложности.
2. Удерживайте входы, инструменты и критерии постоянными. Зафиксируйте модель, режим и источник цены или фактическое потребление.
3. Рекомендуйте вариант по каждому классу задач. Покажите примеры, где цена и задержка растут, а результат не улучшается.
