# Адаптивный эскиз страницы

В Claude Code прочитайте CLAUDE.md и найдите источники токенов через Glob и Grep. Если браузер недоступен, приложите статические замеры и перечислите ручные проверки.

1. Выделите обязательные действия и порядок чтения. Возьмите реальные короткие и длинные варианты текста.
2. Соберите эскизы для узкого, среднего и широкого экрана. Определите переходы по моменту, когда текст, карточка или навигация перестают помещаться.
3. Проверьте переносы, последовательность фокуса и место для состояний ошибки и загрузки. Сдайте эскизы и список размеров, где меняется компоновка.
