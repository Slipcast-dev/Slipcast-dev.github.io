# Редактирование и пакетный экспорт изображений

Возьмите правила именования и хранения мастеров из CLAUDE.md. Через Glob найдите нужные варианты исходников, через Read откройте таблицу размеров и существующие настройки. Для единообразных преобразований переиспользуйте локальный сценарий через Bash. Сложные маски и ретушь ведите в редактируемом мастере.

1. Разложите правки по исходникам и целевым форматам. Проверьте поля кадрирования, ориентацию, цветовой профиль, альфа-канал и ограничение размера файла. Согласуйте фон для форматов без прозрачности.
2. Прогоните один тестовый файл каждого класса, например портрет с EXIF-поворотом, изображение с встраиваемым ICC и графику с альфа-каналом. Проверьте экспорт визуально и по метаданным. Запишите точные параметры преобразования.
3. Составьте явную карту путей и найдите совпадающие назначения до пакетного запуска. Запишите результаты отдельно от мастеров. Для пропущенных файлов запишите причину и проверьте количество выходных файлов по карте. Сопоставьте профили, размеры и альфа-каналы с заданием.
4. Передайте карту с коротким журналом правок и способом повторить экспорт. Если редактор или просмотрщик недоступен, укажите, какой этап проверялся только по метаданным.
