# Сверка результатов импорта

В Claude Code проверь CLAUDE.md и путь к фикстурам. Сначала прочитай схему, затем используй Bash для проверки в изолированной базе, если он доступен.

1. Зафиксируй таблицу ожидаемых итогов: входные строки, принятые записи, отклонения, обновления, дубли и правила сопоставления ключей.
2. Используй отдельное тестовое хранилище. Сними состояние до импорта и после него. Приведи происхождение каждого расхождения до строки или JSON-пути.
3. Повтори импорт того же файла и проверь правило повторного запуска. Для импортов с частичным успехом проверь, что принятые и отклонённые записи отражены ровно один раз в соответствующих итогах.
4. Собери компактный отчёт с фактическими счётчиками, причинами отклонений и ссылками на тестовые файлы. Отметь сценарии, для которых не удалось запустить импорт.
