# Приёмка веб-интерфейса в браузере

1. Запусти штатную локальную версию и выдели один–три сценария по запросу пользователя. Для каждого зафиксируй стартовый адрес, действие и наблюдаемый критерий успеха.
2. Пройди сценарии с клавиатуры. Проверь Tab и Shift+Tab, а для диалогов и меню также Escape, возврат фокуса к открывшему элементу и сохранение видимого фокуса. Сверь подписи интерактивных элементов и сообщения об ошибках в дереве доступности, если его можно открыть.
3. Повтори основные шаги при ширине мобильного экрана и увеличенном масштабе. Зафиксируй обрезку текста, неожиданную горизонтальную прокрутку и перекрытые элементы. Для динамической страницы проверь ожидаемое состояние при загрузке и при пустом ответе на локальных данных.
4. Для каждого дефекта укажи маршрут, браузер, размер окна, шаги, ожидаемое и наблюдаемое поведение. Отдельно отметь среды, где проверка не запускалась. Автоматические проверки помогают находить дефекты, а клавиатурный проход подтверждает пользовательский сценарий.

Результат — короткий отчёт приёмки с воспроизводимыми наблюдениями и точечными исправлениями по запросу.

## В Claude Code

Прочитай локальные правила CLAUDE.md. Используй существующие тесты через Bash и уже подключённые средства браузера Claude Code. Оставь короткую сводку ручных шагов для сценариев, где инструмента нет.
