# Регрессия состояния фронтенда

В Claude Code сверьте CLAUDE.md, найдите компонент и тесты через Grep и делайте проверки штатными командами через Bash.

1. Зафиксируйте ожидаемое состояние при первом входе, выборе фильтра, перезагрузке и возврате по истории.
2. Пройдите один и тот же путь через клавиатуру и указатель. Сверьте URL и видимые значения, а тестовые данные держите стабильными между прогонами.
3. У каждого расхождения укажите шаг, ожидаемое и полученное состояние. Добавьте тест на публичное поведение, если меняете код.
