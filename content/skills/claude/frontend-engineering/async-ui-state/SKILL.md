# Асинхронные состояния интерфейса

В Claude Code сверьте CLAUDE.md, найдите компонент и тесты через Grep и делайте проверки штатными командами через Bash.

1. Запишите допустимые переходы между загрузкой, пустым списком, результатом и ошибкой. Определите, какой ранее полученный результат можно сохранить.
2. На заглушке проверьте два запроса в обратном порядке, повтор после ошибки и уход со страницы. Устаревший ответ не должен перекрывать актуальный.
3. Проверьте, что статус обновляется для клавиатуры и средств чтения с экрана. Сдайте таблицу переходов и результаты тестов.
