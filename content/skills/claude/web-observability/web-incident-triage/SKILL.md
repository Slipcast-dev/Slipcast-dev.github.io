# Разбор сбоя веб-приложения

В Claude Code начните с CLAUDE.md, используйте Read или Grep для предоставленных журналов и Bash только для локальной проверки.

1. Зафиксируйте версию сборки, маршрут, период и основной симптом. В журнале отделите первый сбой от каскада последующих сообщений.
2. Сопоставьте одно действие пользователя с журналом браузера и записью тестового сервиса. Воспроизведите его на локальной версии с очищенными данными.
3. Сдайте хронологию, подтверждённые факты и гипотезы. Для каждой гипотезы предложите одну измеримую проверку.
