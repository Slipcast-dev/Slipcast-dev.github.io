# Изменения

## Навигация и установка коллекций — 2026-11-11

- «Скиллы и агенты» и «Разработчик» поменялись местами в главном меню.
- Ссылки «Установка» ведут на последний релиз каждой коллекции.

## Скиллы и агенты — 2026-11-11

- На главной добавлена кнопка под «Проекты»; все четыре кнопки имеют одинаковые размеры.
- Добавлен двуязычный раздел с коллекциями Codex и Claude Code, фильтрами, каталогами и инструкциями установки.
- Две коллекции исключены из общего списка проектов на этапе синхронизации и при отображении сохранённых данных.
- Проверены маршруты, локализация, фильтры и сохранение остальных проектов.

## Общий поиск кириллицей и латиницей — 2026-11-05

- Частное правило Grizzly заменено общей транслитерацией и нормализацией букв для всех карточек, включая будущие.
- Исходное написание по-прежнему участвует в поиске; числа и версии не сокращаются.
- Добавлены проверки текущих названий, русского описания латиницей, будущих карточек, смешанных запросов и отсутствия ложных совпадений на пустом ключе.

## Поиск Grizzly по русскому названию — 2026-11-05

- В поисковый индекс Grizzly добавлены варианты «гризли» и «гриззли»; название карточки сохранено.
- Проверены кириллический ввод, регистр, частичное название, сочетание с описанием и работа в английском интерфейсе.

## Поиск по карточкам проектов — 2026-11-05

- Под заголовком добавлено адаптивное поле поиска в зелёном терминальном стиле.
- Фильтрация по названию, описанию и версии работает локально, без учёта регистра, с поддержкой нескольких слов.
- Добавлены RU/EN подписи, доступное сообщение об отсутствии результатов, сброс по Escape и сохранение запроса при обновлении проектов.
- Добавлена проверка поиска, очистки, локализации и сохранения фильтра.

## Компактные карточки проектов — 2026-11-05

- Уменьшены минимальная высота карточек, внутренние отступы и промежутки между проектами на компьютерах и телефонах.
- Сохранены размеры и начертание шрифтов, межстрочные интервалы и контраст текста; карточки растут по содержимому и не обрезают описание.

## Исключение портфолио из проектов — 2026-11-03

- Карточка репозитория профиля `Slipcast-dev` убрана из раздела проектов и начального снимка данных.
- Репозиторий исключается из последующих синхронизаций и отображения без учёта регистра имени; добавлены проверки обоих фильтров.

## Ускорение обновления публичных проектов — 2026-11-03

- Проверка публичных репозиториев запускается каждые 10 минут вместо одного раза в час; расписание GitHub может задерживаться.
- Открытый раздел проектов проверяет опубликованный JSON раз в 2 минуты вместо 15, сохраняя карточки при ошибках сети.
- GitHub API по-прежнему вызывается только в Actions; токены не передаются посетителям.

## Обновление русской ссылки для превью — 2026-11-03

- Добавлен `index-ru.html` с собственными canonical и Open Graph URL.
- Русская навигация при публикации использует отдельный языковой адрес.
- Подтверждено отсутствие старого описания и баннера в новых метаданных.

## Обновление метаданных — 2026-11-03

- Описание ссылки RU: «Программное обеспечение, ИИ Агенты, Скилы».
- Описание ссылки EN: Software, AI Agents, Skills.
- Добавлены Open Graph и Twitter description непосредственно в HTML.
- Сборка создаёт `index-en.html` с английским превью, отдельным canonical и языковыми метаданными.
- Переключатель языка и ссылки главной страницы учитывают английский адрес.
- Добавлена проверка обеих версий метаданных без выполнения JavaScript; всего 11 тестов.
- Уточнены инструкции для локальной копии, готовой сборки и просмотра RU/EN.

## 2.0.0 — 2026-11-03

- Старый сайт заменён терминальным интерфейсом с четырьмя страницами.
- Добавлены русский и английский языки, автоопределение и ручной переключатель.
- Размещены биография, аватар и ссылка на чат Telegram.
- Добавлены публичные проекты с версиями и две карточки сайтов с живыми превью.
- Обновление GitHub API перенесено из браузера в почасовую сборку GitHub Actions.
- Настроены статическая сборка, проверки, CSP, sitemap, robots, favicon и страница 404.
- Удалены старые файлы Astro, зависимости, неподходящие тесты и устаревшая документация. История Git сохранена.
