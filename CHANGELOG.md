# История изменений

## 2026-10-27

- Проведён аудит исходников, npm-зависимостей, доступной Git-истории и настроек GitHub.
- Включены Dependabot alerts, security updates и ограничение Actions официальными GitHub Actions с обязательным SHA pinning.
- Прямые Actions закреплены на проверенные commit SHA; checkout не сохраняет credentials, npm lifecycle-скрипты при установке отключены.
- В CI добавлены npm audit и таймауты; привилегии публикации отделены от сборки и pull request.
- Добавлены production CSP, Referrer Policy, проверки CSP и безопасности workflow.
- Добавлены SECURITY.md, CODEOWNERS, Dependabot и отчёт аудита.
- Зафиксирована повторная приватность репозитория: защита main и Pages недоступны на текущем тарифе. Возвращена явная проверка хостинга без изменения видимости.

## 2026-10-26

- Исправлены переходы к релизам: отдельные доступные ссылки вместо значков внутри ссылки на репозиторий.
- Повышен контраст вспомогательного текста и тегов, добавлено единое выделение фокуса ссылок.
- Данные витрины вынесены в типизированный модуль и обновлены через публичный GitHub API.
- Удалена карточка приватного репозитория, недоступная посетителям сайта.
- Добавлен скрипт синхронизации описаний, версий, prerelease и сортировки по последнему push.
- Настроено ежедневное обновление данных при публикации без автоматической записи в Git.
- Добавлены canonical, og:url, Open Graph PNG 1200 × 630 и Twitter Card; базовый адрес исправлен на адрес публикации GitHub Pages вместо неподключённого домена.
- Созданы фирменный баннер и информационные панели для README.
- Astro обновлён с 5 до 7; поддерживаемая версия Node.js — от 22.23.4, рекомендуемая — 24.
- Добавлены проверка типов, регрессионные тесты HTML и контраста; CI проверяет PR и сборки перед публикацией.
- README переписан под фактическое поведение проекта.
- Удалён служебный файл Finder, уточнён .gitignore для него и локальных секретов.
- После перевода репозитория в публичный включён GitHub Pages с источником GitHub Actions. Временный пропуск deploy и предупреждение о тарифе удалены; публикация снова обязательна для успешного workflow основной ветки.
