Установка и обновление

Скачайте ZIP для своей платформы и распакуйте его. Из папки skills/ копируйте нужные папки целиком, вместе с SKILL.md и остальными файлами.

Codex

Для этого проекта
.agents/skills/
Для всех проектов
~/.agents/skills/
Вызов в сессии
$skill-name
Документация Codex

Claude Code

Для этого проекта
.claude/skills/
Для всех проектов
~/.claude/skills/
Вызов в сессии
/skill-name
Документация Claude Code

Для обновления скачайте свежий ZIP и замените папки обновляемых скиллов. Если ваш скилл изменён вручную, сначала сохраните эти правки. Если скилл не появился, откройте новую сессию в нужном проекте.

В MODEL_GUIDE.md внутри каждого ZIP указаны модели для обычных и сложных задач. Выбор модели выполняется в вашей сессии.

    Для выбранной среды пока нет скиллов.
